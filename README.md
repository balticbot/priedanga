# Priedanga

Offline-first public warning and shelter app for Lithuania. Works with full network, a congested network, or no network at all.

- **Priedanga** — the citizen app: signed alerts, offline shelter finder, offline guidance in 5 languages.
- **Tiltas** — the offline Bluetooth mesh that relays signed alerts phone to phone.

Status: early development. Not affiliated with or endorsed by any government body. Only TEST alerts are issued.

## Repository layout

| Path | What |
|---|---|
| `packages/alert-format` | Trust core: signed alerts, certificates, revocation, manifests ([SPEC](packages/alert-format/SPEC.md)) |
| `packages/content-builder` | Builds signed content packs from official open data (PAGD registers, Address Register) |
| `content/guidance` | Guidance and first-aid topics (LT/EN/RU/PL/UK) with cited official sources; bundled into the signed pack |
| `content/checklists` | Preparedness checklists (go-bag, 72 h supplies, family plan) from PAGD guidance |
| `packages/region-builder` | Builds offline region packs: map tiles cut from the Protomaps OpenStreetMap build + walking network, signed; A* walking routes |
| `packs/dev` | Current dev content pack (12k+ shelters, KAS, evacuation points, sirens), signed with a dev key |
| `packages/relay` | Relays official PAGD warning messages as signed alerts (relay role), with a dev feed server |
| `packages/tiltas` | Tiltas Bluetooth mesh protocol: [SPEC](packages/tiltas/SPEC.md), reference implementation, crowd simulation, frame vectors |
| `apps/mobile/modules/tiltas` | Tiltas native engines: Swift / CoreBluetooth (also a SwiftPM package with vector tests and a macOS test peer) and Kotlin / Android BLE with a foreground service |
| `apps/mobile` | Expo (React Native) app: offline shelter finder, live alerts from the relay feed, LT/EN/RU/PL/UK |

## Development

```bash
npm install
npm run build:packages     # build alert-format + content-builder
npm test                   # all workspaces
npm run pack               # refresh packs/dev from data.gov.lt and content/ (creates dev keys in secrets/dev on first run)
npm run pack -- --offline  # rebuild from the download cache, e.g. after editing content/guidance
npm run web -w @priedanga/mobile    # run the app in a browser
npm run region -- build kaunas      # build a region pack (kaunas, vilnius) into packs/regions/ (git-ignored) and refresh index.json
npm run region -- serve             # serve packs/regions on :8788 for in-app downloads (EXPO_PUBLIC_REGIONS_URL)
npm run region -- fonts             # refresh the map label glyphs in apps/mobile/assets/glyphs
npm run relay -- serve              # serve the signed PAGD relay feed at http://localhost:8787/feed.json
npm run relay -- serve --demo red --demo-area "Kauno m."   # plus a clearly labelled TEST alert
(cd apps/mobile/modules/tiltas/ios && swift test)            # Swift Tiltas frames against the shared vectors
npm run offers -w @priedanga/tiltas > /tmp/offers.json       # live feed alerts as offers for the Mac test peer
(cd apps/mobile/modules/tiltas/ios && swift run tiltas-peer --offers /tmp/offers.json)   # Mac serves them over Bluetooth
```

Tiltas needs real Bluetooth: the iOS Simulator has none (the app shows "not supported" there). Test with a phone (iPhone dev build or Android release APK) next to the Mac peer, or two phones. Android build: OpenJDK 17 + Android SDK, `npx expo prebuild -p android`, `cd apps/mobile/android && ./gradlew assembleRelease`, install with `adb install -r app/build/outputs/apk/release/app-release.apk`.

The app reads the feed from `EXPO_PUBLIC_FEED_URL` (default `http://localhost:8787/feed.json`, reachable from the iOS Simulator).

Dev keys live in `secrets/dev/` and are never committed. If you rebuild the pack with new dev keys, update `apps/mobile/src/trust/root.ts` with the new root public key (`packs/dev/DEV_ROOT_PUBLIC_KEY.txt`); a test checks they match.

Map data © OpenStreetMap contributors (ODbL), tiles via Protomaps. Region packs are downloaded in the app (Offline maps screen) and installed only after signature and hash checks; set `PRIEDANGA_BUNDLE_REGIONS=1` to bundle them into a dev build instead.

Data: Priešgaisrinės apsaugos ir gelbėjimo departamentas prie VRM and Registrų centras via data.gov.lt, CC BY 4.0.

### Native iOS build

Requires Xcode (iOS 27 SDK) and CocoaPods. Expo SDK 58 or newer is required: iOS 27 terminates apps that have not adopted the UIScene lifecycle.

```bash
npm run ios -w @priedanga/mobile                                         # debug build on the booted simulator
cd apps/mobile && npx expo run:ios --configuration Release   # release build for realistic timings
```

`ios/` and `android/` are generated by `expo prebuild` and not committed. The `plugins/withQuotedBundleScript` config plugin keeps the build working when the repo path contains spaces.

Measured on the iPhone 17 simulator (iOS 27.1), release build, cold start: pack load 211 ms, of which ~165 ms is the two Ed25519 checks in pure JS. Moving signature verification to a native module (planned together with Tiltas) removes most of that.
